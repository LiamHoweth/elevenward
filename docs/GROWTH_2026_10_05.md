# Elevenward free growth improvements

This batch adds a discovery path to the existing career-card share flow and a
player-initiated studio portfolio entry under More. There are no new backend
services, paid SDKs, account requirements, rewards, purchase changes or new
analytics events.

## Public website configuration

`config/marketing.json` contains the public website origin already used by the
studio. Source reads `ELEVENWARD_STUDIO_WEBSITE_URL` at build time and accepts
only an HTTPS origin without credentials, paths, queries or fragments. Missing
or invalid configuration hides studio discovery and leaves ordinary card sharing
usable without an outbound link. The release workflow includes the public file.

The configured destinations are `https://howethstudio.com/elevenward/` and the
currently live studio homepage, `https://howethstudio.com/`. The latter already
lists the portfolio and needs no unpublished route. Website publication and
store availability are independent of this app change; these actions contain
no guessed store identifier.

```sh
flutter test --no-pub --dart-define-from-file=config/marketing.json
flutter build ios --release --no-codesign --no-pub \
  --dart-define-from-file=config/marketing.json
```

For an otherwise configured release, retain its authentication/content/purchase
definitions and append `--dart-define-from-file=config/marketing.json`:

```sh
flutter build ipa --release \
  --dart-define-from-file=config/production.json \
  --dart-define-from-file=config/marketing.json \
  --export-options-plist=ios/ExportOptions.plist
```

The file is public configuration, not a credential store. The fixed UTM values
identify only the app, medium, and campaign (`career-share-v1` or `portfolio-v1`)
and contain no account, save, player, friend, or installation identifiers. A URL
tag alone does not measure installations or provide deferred deep linking.

## Player behavior

- Sharing remains voluntary in the existing Legacy/retirement card flow. The
  caption adds a localized discovery link; the image includes a readable product
  URL so an image-only post retains its destination.
- The graphic uses a fixed 360 × 450 canvas with a full localized spoken summary;
  surrounding buttons preserve text scaling. Share failures show a localized
  retry message and release the rendered image.
- More opens the portfolio in the platform browser only when the player taps the
  entry. Failure leaves the career in place and shows a localized retry message.
- Existing iOS system reviews remain after a completed season, regardless of
  win/loss or sentiment, with a 120-day cooldown and one request per app version.
  International tournament completions and declined call-ups now reach the same
  opportunity. The delayed request cancels when the Career tab is hidden, another
  route is open, the app is inactive, or the career has changed. No sentiment
  gating, incentives or custom rating prompt were added.
- Existing opt-in analytics and its server contract are unchanged.

## Recommended next steps

Prioritize truthful App Store copy, the first screenshots, a clear first career,
and actual gameplay clips before acquiring traffic. Compare store page views,
downloads and returning players using existing store reports; a paid attribution
SDK or new Railway analytics service is unnecessary at this stage. Review native
share destinations and browser behavior on a physical device before release.

Defer paid ads, referral rewards, push notification infrastructure, and paywall
experiments until the current build is qualified and baseline conversion and
retention are available. Local reminders are a later candidate if players ask
for them; they should be optional and tied to meaningful gameplay.
